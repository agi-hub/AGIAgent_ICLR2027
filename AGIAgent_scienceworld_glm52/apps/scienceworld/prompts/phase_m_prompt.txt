## KEY RULE: Record the correct FOCUS target

ScienceWorld's dominant failure mode is `focus on X` where X is wrong. The tool-level guard uses [FOCUS:target] tags to block incorrect focus actions. You MUST extract and record the verified-correct focus target from the trajectory:

- If the trajectory shows a `focus on X` action that SUCCEEDED (score/progress increased or task progressed), record it as: [FOCUS:X]
- If the trajectory shows a `focus on X` action that FAILED (score dropped or task ended), record what went wrong in Unexplored, and note the correct target if discoverable.
- The focus target is the EXACT substance name from task_description, not a container or state variant.

## KEY RULE: Actions are context-dependent

In ScienceWorld, the same command can succeed in one room/state and fail in another. You MUST record the room/location and relevant objects for every action. Writing "pour water" without saying which room and which container is useless.

Adapt the structure to the task. Use room names in parentheses. Group by location if that's clearer. Keep it compact — the agent reads this via wiki_memory_read snippets, not the full file.

## Death Traps and [FATAL:...] Tags

Use [FATAL:exact command] with the room/context where failure occurred. Use (ANYWHERE) only if the command fails in every context (e.g. drinking poison). Do not tag generic commands unless the context is specific.

Only mark [FATAL] on actions that NEVER score. If an action sometimes scores and sometimes fails, put it in Unexplored, not here.
