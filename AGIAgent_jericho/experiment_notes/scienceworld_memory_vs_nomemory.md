# ScienceWorld 持续学习对照实验报告(有记忆 vs 无记忆, n=3)

> 日期: 2026-10-10 首跑, 2026-11-13 n=3 定稿 | 数据源: `/mnt/data/AGIAgent_scienceworld_glm52/data/benchmark_results/`(无记忆: sw_glm52_63_nomem + sw_63_nomem_round3-5 / sw_63_nomem2_round1-5 / sw_63_nomem3_round1-5; 有记忆: sw_63_iterative_r1/r2/r3; 筛选源: sw_glm52_test_full)
> 任务集: 63 个困难任务对(211 对面板中首次尝试 <100 的子集); 每臂 3 次独立采样

---

## 一、实验设计

### 1.1 为什么要这样设计(测量问题的由来)

论文原表(44.4 → 70.0, +25.7pp)来自单个有记忆运行(`sw_glm52_test_full`, 2026-08-06, 211 对, 真 GLM-5.2)内部: 筛选出 R1<100 的 63 对, 比较 R1/R2。该口径有两个无法在原数据内剥离的混杂:

1. **选择偏差/均值回归**: 按"R1<100"筛选本身使 R2 偏高(选中的是下行噪声, 重测自然回升);
2. **best-of-k 效应**: R2 只对未解任务继续, 多轮累计天然高于单轮。

因此设计了**同构对照**: 有记忆与无记忆两条臂使用完全相同的 won-skip 逐局结构、同一任务集、同一模型, 唯一差异 = 跨尝试记忆的有无——两个混杂在相减时抵消, 差值即记忆净效应。

### 1.2 轮次编号约定

"第1局"= 原始 211 对运行的筛选轮(两条臂复用同一份筛选结果, 不重跑); 无记忆臂与有记忆臂各自从"第2局"起在自己的臂内逐局推进。

### 1.3 两条臂的配置(差异明示)

| 配置项 | 无记忆臂 | 有记忆臂 |
|---|---|---|
| 运行 | r1 = v1 + round3/4/5 链; r2 = nomem2_round1-5 链; r3 = nomem3_round1-5 链 | r1/r2/r3 = sw_63_iterative_r1/r2/r3 |
| 模式 | `--baseline --loops 100`(**baseline 模式**: 每任务单局, 无 phase_m, 无 wiki, 提示词明令"Do NOT call wiki_memory_read") | `--play-loops 100 --phase-m-loops 15 --max-iterations 5`(**iterative 模式**: 局间策展+wiki 检索) |
| 每局步数 | 100 | 100 |
| won-skip | **手动链式**(脚本读上局 score_summary, 满分任务不再进入下局 task-list) | **内建**(won 后剩余 attempt 标 skipped, best=None) |
| 模型 | 名义 glm-5.2, coding 端点实际 GLM-5.3 | 同(同一端点同期) |
| 并行 | r1: 6/8; r2/r3: 3 | r1/r2: 8/3; r3: 3 |
| key | 官方 coding(老 key) | 同 |

**实现层面的等价性说明**:
- 无记忆臂的"每局重跑未解任务"由链式脚本(`run_nomem_rounds345.sh` / `run_nomem2_full_chain.sh` / `run_nomem3_full_chain.sh`)用独立实验串接实现(每局一个 benchmark_results 目录), 与 iterative 内建的 skip 语义一致(均按"上一局未达 100"筛);
- 有记忆臂 R1 时 wiki 为空, 与 baseline 模式的差别仅在提示词框架("attempt 1 of 5, no prior knowledge" vs "no-memory baseline rules"); 无记忆臂首局三采样 73.0/73.4/69.4, 有记忆臂 R1 三采样 65.4/71.9/69.2(首局方差 ~7pp, 属正常运行间波动);
- 记忆内容: 有记忆臂 R2 起检索本运行 R1 起累积的 experiences+语义页(不继承任何历史运行)。

### 1.4 测量口径

- **存活均值**: 该局实际执行任务的 score_rate 均值(满分退出者不计——两边同规则);
- **本局新解**: 该局 score_rate==1.0 的任务数;
- **累计解 / 累计 best**: 跨局并集(任一局达 100 记为解; best 取各局最大值)。这是跨臂对比的主口径。

## 三、结论

1. **记忆净效应为正且温和, n=3 高度稳定: 累计 best +7.0pp(85.2±0.2 → 92.2±0.4), 满分 +11.7 个任务**(同结构同模型对照, 选择偏差与 best-of-k 在相减中抵消)。两臂各自三采样的离散度(±0.2/±0.4)远小于臂间差, 结论非采样运气。
2. **记忆的主要作用在首次重试局**: 有记忆 R2 新解 18/14/11(均值14.3) vs 无记忆第2局 8/9/7(均值8.0)——记忆把重试命中率提高 ~80%, 三采样全部复现; 第3局起两臂都收敛到硬核任务, 增量趋同。
3. **论文 44.4→70.0 的 +25.7 中约三分之二是选择偏差与 best-of-k 效应**(~17-19pp), 真实记忆增量 ~7pp——与无记忆重测(73.0/73.4/69.4)已接近 70.0 的观察一致。
4. **ScienceWorld 的记忆增益远小于 Jericho(+20pp)**: 符合任务性质——Jericho 同任务精确重复(路线可整条复现), ScienceWorld 变体间仅部分程序可迁移。记忆增益与任务重复度正相关, 为论文的适用范围限定提供定量依据。
5. 有记忆臂首局采样(65.4/71.9/69.2)与无记忆首局(73.0/73.4/69.4)重叠, 波动 ~7pp 属运行间方差, 不构成"记忆有害"的证据; 两臂对比以累计口径为准。

### 3.1 R1 起点差的说明(有记忆 R1 三采样均略低: 68.8 vs 71.9)

三次采样同号(65.4<73.0, 71.9<73.4, 69.2<69.4)但幅度收敛(−7.6→−1.5→−0.2, 均值 −3.1pp)。R1 时两臂唯一受控差异是提示词框架("single-attempt, no restart" vs "attempt 1 of 5, explore from scratch" 及策略段措辞), 属提示词敏感度效应; 行为数据排除"提前放弃"假说(R1 步数均值 48.0 vs 44.0, 中位 47 vs 45, 用满步数比例相当)。该混杂不影响记忆净效应测量(每臂 R1 即本臂基线, 净效应来自臂内 R1→R2 提升与累计曲线 R2 起的反超)。
