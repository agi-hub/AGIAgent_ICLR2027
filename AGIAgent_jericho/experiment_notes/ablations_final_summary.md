# 第二部分:最终分析

## 2.1 增益归因(阶梯)

```
底座 33.6
  └─ +跨局检索可验证事实 ──→ 49.6~49.7(任何记忆形态, +16pp, 最大单项)
       └─ +有序 gist(顺序+因果+结论) ──→ 55.0~55.7(再 +5~6pp)
            ├─ 程序预抽取(−2.5) ──→ 53.2
            └─ LLM 直读(基准) ──→ 55.7
                 └─ +语义页/门(−0.7, 方差内) ──→ 55.7(主方案)
```

**结论**:
1. **全部增益的绝大部分(+16pp)来自"跨局检索可验证事实"本身**——无论什么形态的记忆, 有就比没有强得多;
2. **gist 化(有序+因果+结论)再买 5-6pp**, 且损失结构逐游戏清晰: 散点化在顺序敏感游戏(Balances −12.5/Zork3 −11.9)受害, 集合型知识(Library +8.2)反而更优; 去时序额外伤检索定位(Zork3 −20.5/Library −17.8);
3. **语义页+门对均值零贡献**(两种抽取方式下均 ±1pp 内), 定位为信任/审计层;
4. **程序预抽取是唯一负资产组件(−2.5pp)**: 固定解析规则丢零分关键信号(Zork3 牺牲性得分), LLM 直读捕获更全; 程序的价值只剩确定性/数字保真/token 效率(弱 curator 模型场景才兑现)。

## 2.2 表示形态的边界

- **均值口径最优 = gist; 上限口径最优 = 纯实录**: E6 的 best 583(全场最高)与 Final 66.0 显示无压缩直读上限更高, 但方差大(Zork1 局间 sd 13.6, 重踩死亡坑)、慢热(Library 卡 8 局)——**整理买的是稳定性与起步速度, 不是信息也不是上限**;
- 纯实录 10 局 332KB(单文件最大 75KB≈19K tokens)已接近"开局全读"的实用边界; 50+ 局协议下 gist 压缩(40 倍)成为物理必需。

## 2.3 外部基线差距的机制

- **RecMem(32.4)**: 官方三层记忆(递归固化→原子事实)。干净重跑确认低分非环境因素——Zork1/Zork3/Balances 的 look 死循环(40-54%, 三跑一致)是**原子事实表示的固有缺陷**: 检索命中的散点无"接下来去哪"的路线信息。Qdrant 实测: 366 条原子事实 58% 不含得分信息; 固化有损删除原始记录(subconscious 仅剩 2 条);
- **EvoTest(37.7)**: 官方 scaffold(prompt 进化+UCB)。记忆为单步 (state,action,Δ) 散点(Detective 465 条, 同一 +100 动作存 4 遍, 无序), top-3 注入给执行者拼不成路线; 负例记忆只供进化器、执行时不可见。thinking 开启时降至 28.8(400-token 动作预算被思考挤压);
- **AutoManual 式(53.0)**: 手册即上下文(30 条目预算+失败归因+验证标记, 常驻 prompt)。与主方案差距仅 2.7pp——证明"完整手册常驻"接近"gist 检索"的效果, 是真正的最强竞品; 其弱项 Temple 37.1%(手册压缩丢细节)。

## 2.4 门(FATAL 拦截)的最终定位

均值贡献 0.0(n=2 双向: full 53.2 = −门 53.2); 但 0 分局 0% vs 无门 5%(n=2), 拦截全程留痕可审计。**门 = 保下限、降方差的保险机制, 非性能引擎**; 在"得分性死亡"游戏(Zork3 牺牲/Balances 风险探索)反是负资产(过阻塞 17%)。

## 2.5 组件价值总结(论文叙事)

| 组件 | 均值贡献 | 保留价值 |
|---|---|---|
| 情景 gist 通道 | **+21pp(全部)** | 性能载体 |
| gist 化(vs 散点/乱序) | +5~6pp | 顺序与因果承载(集中顺序敏感游戏) |
| LLM 直读(vs 程序预抽取) | +2.5pp | 捕获规则外信号 |
| 语义页 | 0 | 压缩(5×)/溯源(59/72 事件)/可审计/门的载体 |
| FATAL 门 | 0 | 0 分局 0% vs 5% + 拦截记录 |

**N=50 长程补充(2026-10-08)**: 主方案 50 局 Mean=64.8(前 10 局 55.1→后 10 局 68.4), 学习不在 10 局饱和; 长档案(150KB/游戏)未压垮检索; 且与 EvoTest 论文的 N=50 发表结果(Gemini 47.0/Claude 50.0)构成 matched-N 对照(+14.8~17.8pp, 骨干不同需注明)。

**一句话**: 跨局检索可验证事实承载几乎全部增益; 有序 gist 是均值最优表示; 抽取器直读优于程序; 语义页与门以零均值代价提供可审计性与安全下限; 纯实录的上限最高但方差大——**"存什么、怎么抽"决定均值, "压不压缩"决定可审计性与方差**。
