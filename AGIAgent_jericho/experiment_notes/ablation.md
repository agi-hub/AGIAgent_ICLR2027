## 4. 关键发现

1. **Wiki-Evolve 系统带来 +183% 增益**（full avg 432.8 vs Naive ReAct 152.7），6 个游戏全部正向。
2. **Knowledge (gist 检索) + HardProtect (FATAL 拦截) 是核心**，贡献了总增益的 96.4%（+269.9 avg）。
3. **World Model 有独立价值**（+18% vs Naive ReAct），主要体现在大地图导航类游戏（Detective +20.0, Zork1 +7.5）。
4. **Experience 检索在无 Knowledge 时效果有限**——未压缩的原始轨迹信噪比低，agent 难以高效利用。
5. **Detective 是所有组件的最大受益者**——full (297.0) vs Naive ReAct (60.0)，差距 5 倍。
6. **API 全程无错误**——实验结果可靠，不受 API 限流/500 影响。
7. **full 条件下迭代趋势上升**——Detective 从 ep1 的 130 升至 ep10 的 330；Naive ReAct 条件下无显著学习趋势。

## 5. HardProtect (FATAL) 反事实分析

> 通过轨迹分析估算：如果 full 条件下去掉 FATAL 拦截，agent 在被拦截的动作处继续执行并死亡，各游戏会损失多少分。

### 5.1 FATAL 拦截统计

| Game | 拦截次数 | 误拦截 | 有效拦截 | 被拦截动作 |
|---|---|---|---|---|
| Detective | 6 | 0 | 5 | `east` @ Hallway (→ Dead End 死亡) |
| Library | 0 | — | — | — |
| Zork1 | 0 | — | — | — |
| Zork3 | 0 | — | — | — |
| Balances | 0 | — | — | — |
| Temple | 0 | — | — | — |
| **Total** | **6** | **0** | **5** | |

> 6 次拦截中 play5 有 2 次（r28 和 r34），但第一次拦截后 agent 已被救，第二次不会发生（因为 agent 仍存活）。故有效拦截按首次计为 5 次。所有被拦截动作均不在 scoring path 中（`east` 在 Hallway 不得分），**0 误拦截**。

### 5.2 反事实得分估算

如果去掉 FATAL，5 个 play 的 agent 会在 Hallway junction 执行 `east` → 进入 Dead End → 死亡，分数冻结在拦截时刻：

| Play | 拦截时分数 | 实际最终分 | 无 FATAL 估计分 | 损失 |
|---|---|---|---|---|
| play4 | 70 | 340 | ~70 (死亡) | -270 |
| play5 | 70 | 340 | ~70 (死亡) | -270 |
| play6 | 70 | 310 | ~70 (死亡) | -240 |
| play9 | 70 | 340 | ~70 (死亡) | -270 |
| play10 | 60 | 330 | ~60 (死亡) | -270 |
| **合计** | | **1660** | **~340** | **-1320** |

### 5.3 对总分的影响

| 指标 | full (实际) | full w/o FATAL (估算) | FATAL 贡献 |
|---|---|---|---|
| Detective avg | 297.0 | **165.0** | **+132.0 (+80%)** |
| Detective best | 340 | 340 | 0 (play3 未被拦截) |
| **TOTAL avg** | **432.8** | **300.8** | **+132.0 (+44%)** |
| **Avg %** | **58.3%** | **40.5%** | **+17.8 pp** |

> 估算方式：被拦截的 5 个 play 的分数替换为拦截时刻的分数（死亡点），其余 5 个 play 及其他 5 个游戏不受影响。

### 5.4 Knowledge 路径引导 vs FATAL 硬拦截

Naive ReAct 的 10/10 死亡分布：

| 死因 | 次数 | 被 FATAL 覆盖? |
|---|---|---|
| 餐厅 (north from Outside → restaurant 死亡) | 7/10 | ❌ 不是 FATAL 条目 |
| dazed man (examine man → 牙齿攻击) | 2/10 | ❌ 不是 FATAL 条目 |
| 存活 | 0/10 | — |

Full 条件的死亡分布：

| 结果 | 次数 | 原因 |
|---|---|---|
| 存活 | 8/10 | Knowledge 路径引导避开危险区域 |
| dazed man 死亡 | 1/10 | 路径偶尔偏移 |
| 存活但低分 | 1/10 | — |

**关键发现**：FATAL 只拦截了 1 种死因（Hallway east → Dead End），而 Knowledge scoring path 的路径引导让 agent 根本不接近餐厅和 dazed man 区域。**路径引导（软约束）避免了 9/10 的死亡，FATAL 硬拦截额外救了 5/10。两者互补但路径引导是主要保护机制。**
